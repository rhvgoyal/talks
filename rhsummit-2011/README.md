# Tuning the Red Hat Enterprise Linux 6 I/O Subsystem & Using I/O cGroups

- **Event:** Red Hat Summit 2011
- **Location:** Boston, MA, USA
- **Date:** May 2011
- **Conference page:**
  [Red Hat Summit 2011](https://www.redhat.com/en/about/press-releases/summit-reg-open)

**Authors / Speakers:**  
- Jeff Moyer
- Vivek Goyal

## Abstract
Jeff Moyer discussed how to tune RHEL 6 I/O subsystem to get better performance
and Vivek discussed the newly added feature of block I/O controller and I/O
cgroups and how to use this to achieve isolation betweek workloads.
