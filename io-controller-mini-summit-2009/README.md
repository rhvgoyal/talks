# How to design IO Controller in Linux

- **Event:** IO Controller Mini Summit, 2009
- **Location:** Tokyo, Japan, 2009
- **Date:** October 2009
- **Mini Summit Announcement:**
  [IO Controller Mini Summit, 2009](https://virtualization.linux-foundation.narkive.com/s9MVNDG7/io-controller-mini-summit-2009)

**Authors / Speakers:**  
- Vivek Goyal

## Abstract
Linux community had a desire to add a block I/O controller to the Linux kernel
but there was not agreement on the design. There were many competing proposals
and approaches. Vivek worked on a design of his own and presented that design
at the I/O controller mini summit in an attempt to reach a consensus in the
community.
