## Abstract
Remote attestation is a key pillar in establishing trust for confidential
virtual machine (VM) deployments. Red Hat actively collaborates with upstream
communities—including COCONUT Secure VM Service Module (COCONUT-SVSM), EDK II,
the Linux kernel, Trustee, and others to support remote attestation, UEFI
Secure Boot, and measured boot using Trusted Platform Module (TPM) for
confidential VM environments. Join this session to discover how to run
confidential VMs, enable remote attestation, and see how Red Hat is
contributing upstream to make these capabilities possible.

## Topics
Virtualization, Confidential Computing, Remote Attestation, SVSM
