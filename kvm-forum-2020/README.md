# Long Live Asynchronous Page Fault!

- **Event:** KVM Forum 2020
- **Location:** Held Online due to COVID pandemic
- **Date:** October 2020
- **Conference page:**
  [KVM Forum 2020](https://kvm-forum.qemu.org/2020/)

**Authors / Speakers:**  
- Vitaly Kuznetsov
- Vivek Goyal

## Abstract
Vitaly explained the history of asynchronous page faults handling in KVM and
also explained the improved implementation. Vivek focussed on error handling
in KVM Page Fault. This was needed to make virtiofs + DAX work with page
being truncated on host. Vivek also suggested few possible approaches to
improve the error handling.
