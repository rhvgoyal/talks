# Making Kexec/Kdump work with Secureboot

- **Event:** Linux Plumbers Conference 2013
- **Location:** New Orleans, Louisiana, USA
- **Date:** September 2013
- 🌐 **Conference page:**
  [Linux Plumbers Conference, 2013](https://blog.linuxplumbersconf.org/2013/)

**Authors / Speakers:**  
- Vivek Goyal

## Abstract
When Secureboot came along, Kexec/Kdump did not work with it. This talk
discussed problem statement, challenges and couple of approaches to solve
the problem.
