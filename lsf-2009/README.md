# Block IO Controller and Bio Tracking

- **Event:** Linux Storage and Filesystem Workshop, 2009
- **Location:** San Francisco, CA, USA
- **Date:** April 2009

**Authors / Speakers:**  
- Fernando Luis Vazques Cao
- Nauman Rafique
- Vivek Goyal

## Abstract
Linux was developing Cgroup infrastructure and there was a need to write a
block I/O controller for Linux block layer. There were many people working
to solve the problem and there was no consensus in the community on the
right approach. Fernando, Nauman and Vivek together to present their
approaches to the open source community to make forward progress on this
topic.
